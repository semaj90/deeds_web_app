# ONTOLOGY_RULES

## Purpose
Ontology defines meaning and hierarchy.

Canonical chain:
Packet -> Feature -> Domain -> Community -> Concept -> File

## Hard Rules
- Ontology is NOT topology.
- Ontology is NOT embeddings.
- Communities are NOT domains.
- PageRank is NOT meaning.
- SOM cells are NOT concepts.

## Validation
Every ontology node must have:
- source_ref
- feature_id
- provenance
- replayable evidence
