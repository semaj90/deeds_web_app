# Parent Atlas QAS Bundle

This bundle is intentionally split into:
- OpenSpec design/tasks,
- typed QAS contracts,
- deterministic query-conditioned shadow sampler,
- owner-discovery audit,
- safe NOT_WIRED shadow runner,
- workstation application prompt.

The audit and shadow runner are intentionally conservative because the connected GitHub mirror does not contain the latest workstation files described in the current Parent Atlas work.

Apply from the repository root, inspect the audit output, then bind only to existing owners.
