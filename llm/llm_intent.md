# llm intent

This directory is a human-readable context pack for agents.

## Intended use

- Give future sessions a quick repo map before they touch code
- Summarize the verified structure that usually takes multiple reads to infer
- Provide the agent-facing entrypoints for ACE packet prep and related retrieval work
- Keep repo-root indexing in view so the atlas does not stop at `sveltekit-frontend/`

## Not intended for

- Long prose docs
- Unverified architecture claims
- Replacing source-of-truth code, tests, or configs

## Editing rule

- If a fact can be verified from code, config, or generated output, keep that over prose.
