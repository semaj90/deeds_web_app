## Correct simdjson and retrieval model

simdjson Stage 1 produces temporary structural-position masks and Stage 2 interprets those positions. These are not PostgreSQL bitmap indexes, durable graph structures, or GPU tensors unless a separate, explicit mapping is built. “FP” conventionally means floating point; it is not a simdjson structural-scan term. “MUPS” is not a standard simdjson performance unit; report bytes/s or documents/s and define any benchmark-specific unit.

Recommended bounded flow:

1. Stream JSONL or logical graph subtrees through the existing parser adapter; validate schema and exact byte/source spans.
2. Resolve canonical packet/chunk identities and source/workspace/representation revisions; reject missing or conflicting lineage.
3. Build stable candidate ordinals and bounded CPU-side metadata/CSR or columnar batches. Do not treat parser masks as persistent bitmaps.
4. Keep PostgreSQL authoritative; use existing pgvector/Qdrant and SearchBackend owners for retrieval. Inventory current index configuration read-only; do not create or rebuild indexes in this audit.
5. Establish exact CPU Top-K on one frozen cohort. Only then compare Qdrant, cuVS exact, and CAGRA with identical vectors, filters, metric, ordinals, and deterministic tie handling.
6. Run KMeans/RFF/GEMM only as isolated challengers on qualified batches. KMeans does not require Top-K; RFF approximates an RBF kernel and is not interchangeable with cosine `semantic_768`.
7. Admit revision-qualified evidence through the existing ACE/ContextManifest gate. BitFrost/Valkey may cache qualified descriptors; it cannot confer identity or source authority.

For any refreshed inventory, capture collection/table name, `points_count` and `vectors_count` where available, vector names/dimensions/distance, aliases, quantization, HNSW/IVF parameters, payload indexes, snapshot/collection revision, and a read-only execution receipt. The Oct 6 receipt is a useful historical baseline but does not include every requested Qdrant index/alias field. Keep performance and correctness evidence separate.
