libcudf is a C++ GPU DataFrame library for loading, joining, aggregating, filtering, and otherwise manipulating data. A GPU DataFrame is a column-oriented tabular data structure, so libcudf provides two core data structures: [cudf::column](https://docs.rapids.ai/api/libcudf/stable/classcudf_1_1column "A container of nullable device data as a column of elements."), and [cudf::table](https://docs.rapids.ai/api/libcudf/stable/classcudf_1_1table "A set of cudf::column\").
