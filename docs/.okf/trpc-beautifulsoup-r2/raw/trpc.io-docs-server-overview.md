# Backend Usage
This section covers everything you need to set up and configure your tRPC backend. You'll learn how to define
routers
and
procedures
, set up
context
, add
input validation
, and use
middlewares
to extend your API.
Once your API is defined, you can host it using one of the available
adapters
for platforms like Express, Fastify, Next.js, AWS Lambda, and more.
