# memory/codebase/ — Module Cartridge Index

Symbolic context memory for the sveltekit-frontend codebase.
Generated by `scripts/kb/generate-module-cartridges.mjs`.

## Files

| File | Purpose |
|------|---------|
| `module-cartridges.jsonl` | Full cartridges — one JSON per line, all fields |
| `module-cartridges.min.json` | Compact array — short keys, no import graph, LLM-friendly |
| `module-cartridges.idx.json` | Fast lookup index — stable_key → {kind, source_hash} |

## Regenerate

```bash
# Full regeneration (reads Redis for pagerank, writes Redis cache)
npm run kb:module-cartridges

# Dry run — shows sample output without writing files
node scripts/kb/generate-module-cartridges.mjs --dry-run

# Skip Redis (offline mode)
node scripts/kb/generate-module-cartridges.mjs --no-redis
```

## Cartridge shape (full JSONL)

```jsonc
{
  "stable_key":   "src/lib/server/db/client.ts",   // relative path from sveltekit-frontend/
  "kind":         "server",                         // component|server|route|api|store|schema|mcp|script|test|lib
  "path":         "src/lib/server/db/client.ts",
  "exports":      ["db", "getDb"],                  // named/default exports (max 60)
  "imports":      [...],                            // ImportRef[] { module, names, isType }
  "routes":       [],                               // SvelteKit route paths served
  "tables":       ["cases", "evidence"],            // Drizzle table names from schema imports
  "mcp_tools":    [],                               // MCP tool names from server.tool()
  "tags":         ["database", "drizzle"],          // semantic tags for retrieval (max 16)
  "pagerank":     7.062,                            // Karpathy blend score (Redis, 24h TTL)
  "som_row":      3,                                // SOM grid position (from graph JSON)
  "som_col":      7,
  "summary":      "Primary Drizzle ORM database...", // from JSDoc or Redis wiki note
  "source_hash":  "a3f2b9c1d4e5",                   // SHA-256 prefix (12 chars)
  "generated_at": "2026-05-10T..."
}
```

## Minified shape (min.json)

```jsonc
{ "p": "src/lib/server/db/client.ts", "t": "server", "e": ["db"], "tg": ["database"], "pr": 7.062, "h": "a3f2b9c1" }
```

Short key map: `p`=path, `t`=kind, `e`=exports, `tg`=tags, `pr`=pagerank, `h`=source_hash prefix.

## Redis cache (Phase C)

Each cartridge is cached in Redis at:
```
ace:module:cartridge:{stable_key}   STRING   minified JSON   24h TTL
```

ACE/KAG tools can read a single module's metadata in O(1) via:
```typescript
const raw = await redis.get(`ace:module:cartridge:src/lib/server/db/client.ts`);
const meta = raw ? JSON.parse(raw) : null;
```

## Scoring (Phase D)

`src/lib/server/kb/rerank-weight-loader.ts` exposes `scoreCandidate(features, weights)`.
Weights are loaded from `memory/kb/weights/rerank-profile.json` with fallback defaults.

```typescript
import { scoreCandidate } from '$lib/server/kb/rerank-weight-loader.js';

const score = scoreCandidate({
  pagerank:       7.06,   // from cartridge.pagerank
  semantic_score: 0.82,   // from Qdrant cosine similarity
  tag_matches:    3,      // query tags ∩ cartridge.tags
  export_matches: 1,      // query symbol in cartridge.exports
});
// → 0.0 – 1.0
```
