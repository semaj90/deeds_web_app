# Parent Atlas Agentic File Compiler

## Intent

Compile repository mutation requests into revision-qualified evidence, a bounded Atlas workflow, a runtime workflow dialect, deterministic filesystem effects, validation receipts, and incremental projection invalidation.

## Non-goals

- Do not build another retrieval stack.
- Do not create another context-manifest table.
- Do not let ast-grep mint canonical AST/symbol identity.
- Do not let Mastra snapshots become Parent Atlas source truth.
- Do not give Qdrant, cuVS, CAGRA, DiskANN, or TurboVec independent semantic fusion votes.

## Frozen ownership

Tree-sitter owns structural truth. EmbeddingGemma `semantic_768` owns canonical semantic representation. Postgres owns canonical identity/workflow/provenance/receipts. Qdrant is the persistent semantic projection. cuVS exact is the semantic correctness oracle. CAGRA is hot GPU ANN. DiskANN is cold NVMe ANN. Neo4j/cuGraph consume bounded graph projections. Redis/BitFrost is cache only.
