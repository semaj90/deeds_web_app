## Hard fail-closed invariants

The file aggregator rejects rather than merges when member chunks disagree on:

```text
packetKey
repositoryId
repositoryRelativePath
sourceIdentityKey
sourceRef
workspaceRevision
sourceRevision
```

It also rejects:

```text
empty chunk set
duplicate canonicalChunkId
duplicate chunkRowId
invalid/tampered ChunkRetrievalProfileV2 checksum
```

No directory name, Qdrant point ID, array position, embedding, cluster ID, or
nearest-neighbor result is allowed to mint file identity.
