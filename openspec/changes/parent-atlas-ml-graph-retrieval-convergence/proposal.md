## Why

Track ML and graph retrieval convergence across ranking models, SVD/projection bases, and graph execution while preserving PostgreSQL canonical authority, CPU reference oracles, and strictly gated model promotion.

## What Changes

Establishes gates A through E for ML and graph retrieval convergence:
- Real ranking data with query-grouped splits before new model training.
- CPU model baselines (ListMLE / XGBoost / MLP) evaluated on frozen datasets before any promotion.
- Bounded graph candidate features using NetworkX execution oracles.
- Hardware acceleration (GPU/cuGraph) gated on parity proofs against CPU references.
- Synthesis evidence preserving canonical identity, revisions, and single-vote RRF fusion.

## Capabilities

Adds ml-graph-retrieval-convergence specification governing ML model baselines, graph feature extraction, and acceleration boundaries.
