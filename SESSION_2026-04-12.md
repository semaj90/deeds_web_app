## Key Learnings

### Redis Migration
1. **Singleton deprecation** - Global singleton caused stale connection issues
2. **Connection pooling** - Round-robin distribution prevents connection exhaustion
3. **Type annotations** - Explicit `const redis: Redis = getRedis()` prevents IDE lag
4. **Pub/sub pattern** - Must use `.duplicate()` for dedicated blocking connections

### Zod Validation
1. **100% coverage achievable** - All JSON-parsing routes now validated
2. **Shared schemas** - query-params.ts provides reusable validation schemas
3. **FormData validation** - FormData routes can use Zod with field extraction

### Tooling
