# Parent Atlas Knowledge Bundle

This directory is the portable OKF-facing wiki bundle for the repository.
It contains curated, human-readable concepts and guides. The Parent Atlas
`.okf/` directory remains the owner of domain registries, predicates, schemas,
and extraction policies; this bundle references those contracts but does not
replace their taxonomy.

## Concepts

- [TRACE/Karpathy Runtime Split](project/trace-runtime-split.md) — ownership
  boundaries across orchestration, retrieval, graph, GPU, cache, and synthesis.
- [TRACE/Karpathy Web Development Guide](project/trace-kag-web-development-guide.md)
  — development and retrieval flow for the TRACE/KAG stack.
- [Parent Atlas Retrieval Navigation](project/atlas-retrieval-navigation.md)
  — evidence-first routing from a symptom to the responsible layer.

## Reading rules

1. Read this index before traversing the bundle.
2. Treat each linked Markdown file as a curated concept, not as runtime truth.
3. Follow source references and receipts before promoting a claim.
4. Do not infer taxonomy ownership from directory names or tags alone.
