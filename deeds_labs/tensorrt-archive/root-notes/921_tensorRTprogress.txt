## TensorRT-LLM vs HuggingFace Tensor Name Incompatibility

### TensorRT-LLM Expected Format:
```
transformer.vocab_embedding.weight
transformer.ln_f.weight
transformer.layers.{i}.input_layernorm.weight
transformer.layers.{i}.post_layernorm.weight
transformer.layers.{i}.attention.qkv.weight          # Combined q,k,v
transformer.layers.{i}.attention.dense.weight
transformer.layers.{i}.mlp.gate.weight
transformer.layers.{i}.mlp.fc.weight
transformer.layers.{i}.mlp.proj.weight
```

### HuggingFace Actual Format:
```
language_model.model.embed_tokens.weight
language_model.model.norm.weight
language_model.model.layers.{i}.input_layernorm.weight
language_model.model.layers.{i}.post_attention_layernorm.weight
language_model.model.layers.{i}.self_attn.q_proj.weight    # Separate q,k,v
language_model.model.layers.{i}.self_attn.k_proj.weight
language_model.model.layers.{i}.self_attn.v_proj.weight
language_model.model.layers.{i}.self_attn.o_proj.weight
language_model.model.layers.{i}.mlp.gate_proj.weight
language_model.model.layers.{i}.mlp.up_proj.weight
language_model.model.layers.{i}.mlp.down_proj.weight
```

## Key Incompatibilities Identified

1. **Prefix Mismatch**: `language_model.model.*` vs `transformer.*`
2. **QKV Structure**: HF uses separate q/k/v projections, TRT-LLM expects combined `qkv.weight`
3. **Layer Naming**: `post_attention_layernorm` vs `post_layernorm`
4. **MLP Naming**: `gate_proj/up_proj/down_proj` vs `gate/fc/proj`
