Place local font files here (woff2 recommended). The app expects:

- /fonts/Roboto-Regular.woff2
- /fonts/Merriweather-Regular.woff2
- /fonts/JetBrainsMono-Regular.woff2

You can obtain these from your font source and convert to .woff2 if needed.
Example tools: fontforge, sfnt2woff-zopfli, or online converters.

After placing fonts, restart the dev server (npm run dev or npm run dev:gpu).
