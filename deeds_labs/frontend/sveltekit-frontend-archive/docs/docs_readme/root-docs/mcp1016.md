## 🔧 VS Code Extension Integration

### How It Works

1. **MCP Server** (`scripts/mcp-multicore-server.mjs`)
   - Runs as HTTP server on port 3002/3003
   - 8 worker threads for parallel processing
   - Handles tool requests from VS Code

2. **VS Code Configuration** (`.vscode/mcp.json`)
   - Defines MCP servers
   - Auto-starts with VS Code
   - Capabilities: file_operations, code_analysis, embedding_generation

3. **Tool Routing**
   - VS Code → MCP Server → Tool Execution → Response
   - No extension installation needed
   - Uses built-in Context7 integration

### Example: VS Code Copilot Workflow

```
User in VS Code: "Find similar legal contracts"
    ↓
VS Code Copilot → MCP Server (port 3002)
    ↓
MCP Server → mcp_embed (8 workers) → 625ms
    ↓
MCP Server → rag_search → 180ms
    ↓
Response → VS Code Copilot
    ↓
Display: "Found 5 similar contracts..."
```
