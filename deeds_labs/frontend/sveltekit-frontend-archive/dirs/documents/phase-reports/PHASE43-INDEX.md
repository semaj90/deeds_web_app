## Common Commands

### Verification & Analysis
```bash
# Full error check
npx svelte-check > svelte-check-current.log 2>&1

# Quick summary
npx svelte-check 2>&1 | grep "found"

# Analyze patterns
node scripts/phase43-analyze-top-errors.mjs svelte-check-current.log

# GPU analysis (requires Ollama + Redis)
node scripts/phase43-gpu-json-parser.mjs svelte-check-current.log
```

### Running Fixers
```bash
# Run individual fixer (dry run)
node scripts/phase43-css-syntax-fixer.mjs

# Apply fixes
node scripts/phase43-css-syntax-fixer.mjs --apply

# Run full pipeline
node scripts/phase43-master-dashboard.mjs
```

### Utilities
```bash
# Format after fixes
npx prettier --write "src/**/*.svelte"

# Check specific files
npx svelte-check --filter "src/lib/components/**"

# Sample errors
npx svelte-check 2>&1 | head -100 > sample.log
```

## Workflow Examples

### Daily Development Workflow
1. Make code changes
2. `npx svelte-check > check.log 2>&1`
3. `node scripts/phase43-analyze-top-errors.mjs check.log`
4. Run recommended fixers
5. Repeat

### Weekly Batch Fix Workflow
1. `node scripts/phase43-master-dashboard.mjs`
2. Review PHASE43-DASHBOARD.json
3. Create/run next priority fixer
4. Commit fixed files
5. Update progress tracking

### Emergency Fix Workflow
1. Identify critical error pattern
2. `node scripts/phase43-analyze-top-errors.mjs`
3. Create targeted fixer script
4. Test on sample files
5. Apply with --apply flag
6. Verify with svelte-check

## Troubleshooting

### Common Issues

**Q:** Script fails with "Cannot find module"
**A:** Run `npm install` in sveltekit-frontend directory

**Q:** GPU analysis fails
**A:** Verify Ollama and Redis are running:
```bash
curl http://localhost:11434/api/tags
redis-cli ping
```

**Q:** Too many errors to process
**A:** Use sampling:
```bash
npx svelte-check 2>&1 | head -1000 > sample.log
node scripts/phase43-analyze-top-errors.mjs sample.log
```

**Q:** Need to rollback CSS fixes
**A:** See PHASE43-IMPLEMENTATION-SUMMARY.md → "Rollback Instructions"
