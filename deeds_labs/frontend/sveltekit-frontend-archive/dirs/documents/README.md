- **implementation/** - Implementation-specific documentation
- **integration/** - Integration guides, RAG integration, GPU pipeline documentation
- **phase-reports/** - Phase-specific reports and development milestones
- **system-docs/** - System documentation, indexes, and master documentation
- **testing/** - Testing-related documentation and reports
- **misc/** - Miscellaneous documentation that doesn't fit other categories
