# ⚙️ GPU Setup Guide

This repository includes helpers to enable NVIDIA GPU acceleration (CUDA) for local development and CMake builds.

## ✅ Requirements
- NVIDIA driver 580.88 or newer
- CUDA Toolkit v12.4+ (v13.0 recommended)
- Visual Studio Build Tools 2022 (Desktop development with C++) for native CUDA compilation
- CMake 3.25+ (3.29+ recommended for latest CUDA features)

## 🚀 One-line setup
Open PowerShell as Administrator (recommended) and run:

```powershell
powershell -ExecutionPolicy Bypass -File .\enable-gpu-acceleration.ps1
```

For a preview without writing changes:

```powershell
powershell -ExecutionPolicy Bypass -File .\enable-gpu-acceleration.ps1 -dryRun
```

## 🧪 Verification
Run the verifier script which checks `nvcc` and `nvidia-smi`:

```powershell
.\verify-gpu-build.ps1
```

If nvcc and nvidia-smi are detected and compatible, you're ready to run CMake configure and build.

## ⚙️ How to run CMake → VS Code → GPU build
1. In VS Code, open the project folder.
2. Open the Command Palette (Ctrl+Shift+P) → `CMake: Configure`.
3. If configure succeeds, build using `CMake: Build` targeting the `gpu-release` directory.
4. For faster builds, use the Ninja generator (configured automatically by the helper script).

## 💡 Troubleshooting
- Missing `CMakeOutput.log`: run `CMake: Configure` in VS Code or run `cmake -S . -B build/gpu-release` from a developer PowerShell.
- Permission issues writing to `.vscode/settings.json`: run PowerShell as Administrator or adjust file permissions.
- nvcc not found on PATH: ensure CUDA Toolkit is installed and `C:\Program Files\NVIDIA GPU Computing Toolkit\CUDA\vX.Y\\bin` is present.
- Multiple CUDA versions detected: the enable script will prompt to select one.

## Notes
- The script creates `.vscode/settings.json.bak` before writing changes.
- The script appends CUDA bin/lib paths to VS Code terminal PATH instead of overwriting it.
- The script sets `CMAKE_CUDA_COMPILER` to the detected `nvcc` path and suggests an architecture; you can adjust the architecture after running the script if needed.
