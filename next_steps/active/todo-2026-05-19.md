### Known Gaps (from audit)
| Gap | Impact | Fix |
|-----|--------|-----|
| No CPU limits on non-GPU containers | GPU services can starve CPU workers | Add `cpus: "2"` to postgres, redis, qdrant, rabbitmq, couchdb |
| Caddy reverse proxy 128M limit | Bottleneck for QUIC/HTTP3 streaming | Raise to `256m` / `512m` reservation |
| ClickHouse memory_ratio: 0.8 fragile | Segfault history on the device | Add pre-allocated persistent volume + `start_period: 180s` |
| `image-synthesis` + `tensorrt-llm` each 8G | Can OOM siblings on 16GB VRAM | Document GPU memory lease order: TRT-LLM → langgraph → image |
| No volume backup documented | Data loss risk | Document `docker run --volumes-from` backup pattern for pg/neo4j/qdrant |
| seaweed-volume port 8080 collision | Breaks `dev:gpu` start chain | Fix `npm run dev:gpu` to handle already-running containers gracefully |
