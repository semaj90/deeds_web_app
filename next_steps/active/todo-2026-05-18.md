## Track 7 — XGBoost Cluster Hotness: GraphRAG → Qdrant Tags → CUDA Graph Stream → Bifrost ACE Injection

### Goal
Replace the static Karpathy blend score (`0.4·PR + 0.3·attn + 0.3·authority`) with a **learned XGBoost hotness model** that ingests live Qdrant tag signals, topology autoencoder features, and ACE hit-log feedback — then streams the top-K hot cluster IDs into Bifrost L2 cache and the ACE context packet in real time via a CUDA Graph captured kernel.

### Architecture

```
GraphRAG ingest
  ↓
Qdrant scroll /collections/codebase_chunks_768/points/scroll
  (filter: {must:[{key:"neo4j_gpuCluster",match:{value:N}}]}, with_payload:true)
  ↓
Autoencoder: 768d → 64d topology embedding  (simd-bridge + LibTorch CUDA kernel)
  ↓
Feature vector per cluster:
  [pageRank, attention, authority, chunkHitFreq, somBmuDist, topoClass(OHE), autoenc64d]
  ↓
XGBoost XGBRegressor (LibTorch XGBridge N-API OR Python sidecar)
  predict hotness score → float per cluster
  ↓
CUDA Graph captured stream (cudaGraphCapture → cudaGraphLaunch)
  → writes top-K cluster IDs into Redis sorted set: ace:cluster:hot ZADD score clusterKey
  ↓
Bifrost warmup POST per hot cluster (warmup-bifrost-clusters.mjs --from-hot-set)
  ↓
ACE Stage A0: reads ace:cluster:hot ZREVRANGE 0 9 → inject into bowClusterShould + karpathyMemberShould
```

### Phase A — GraphRAG Ingestion Recommendations for Qdrant Clusters

}

### Phase B — Topology Autoencoder Compression (768d → 64d)

**Goal**: Compress each chunk's 768d content embedding into a 64d topology-aware encoding using the SOM + autoencoder pipeline. Once encoded, the 64d vector carries structural position (som_bmu_row, som_bmu_col), topo_class OHE, and semantic centroid distance — giving XGBoost features that are meaningful without running full ANN.

**Status**: Autoencoder weights are currently Xavier-initialized (random) — flat tanh outputs, all scores ~1.0. Need trained weights before 64d encoding is useful. See `gpu:karpathy:encoded` note in CLAUDE.md.

#### Architecture
```
Input: [768d content_embedding | som_bmu_row | som_bmu_col | topo_class_ohe(8) | centroid_dist]
  ↓ Linear(768+10, 256) → ReLU → Linear(256, 64) → tanh  [encoder]
  ↓ Linear(64, 256) → ReLU → Linear(256, 768+10)          [decoder]
Loss: MSE reconstruction + 0.1×contrastive (same cluster → closer, diff cluster → farther)
```

**Tasks**:
- [ ] `scripts/atlas/train-topology-autoencoder.mjs` — pulls up to 10K embeddings from Qdrant `codebase_chunks_768` (with_vector: true + payload), augments with SOM coords + topo_class OHE, trains autoencoder via LibTorch N-API (`tensorrt_bridge.node`) for 50 epochs, saves weights to `models/topology-autoencoder/weights.bin`
- [ ] `scripts/atlas/encode-clusters-autoencoder.mjs` — loads trained weights, batch-encodes all Qdrant points → 64d → writes to `gpu:karpathy:encoded:{stableKey}` (replaces Xavier-initialized values) and `qdrant:cluster:encoded:{clusterId}` centroid (mean of 64d members) 
- [ ] `src/lib/server/gpu/topology-autoencoder.ts` — TypeScript wrapper: `encodeChunk(embedding768: Float32Array, somRow: number, somCol: number, topoClass: number): Float32Array` — calls LibTorch via N-API; falls back to PCA if weights absent

### Phase D — CUDA Graph Captured Kernel for Hot Cluster Stream

**Goal**: Capture the XGBoost hotness inference + Redis ZADD into a CUDA Graph so that repeated scoring (every 5 min) runs in microseconds instead of milliseconds. The graph captures: feature tensor assembly → XGBoost predict (GPU memory, via libxgboost CUDA backend) → topK selection → Redis write.

**Background**: CUDA Graphs (`cudaGraphCapture`, `cudaGraphLaunch`) eliminate kernel-launch overhead and CPU-GPU sync cost. For this use case (24 clusters, 80 features) the graph is tiny — the value is the **streaming pipeline**, not raw GPU throughput.

```cpp
// In tensorrt_bridge N-API addon:
// cudaGraphBeginCapture(stream, cudaStreamCaptureModeGlobal)
// ... kernel launches: featureAssemble → xgbPredict → topKSelect ...
// cudaGraphEndCapture(stream, &graph)
// cudaGraphInstantiate(&graphExec, graph, ...)
//
// On each call:
// cudaGraphLaunch(graphExec, stream)
// cudaMemcpyAsync(hostScores, devScores, ...)
// cudaStreamSynchronize(stream)
```
