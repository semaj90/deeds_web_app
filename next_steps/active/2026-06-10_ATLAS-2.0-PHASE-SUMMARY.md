## Phase 2B: Neo4j Sync + Community Detection — **READY** 🚀

**Status:** Implementation complete; awaiting operator execution

## Architecture Overview

### Manifold4 Quaternion Structure

**After Phase 2B:**
```json
{
  "manifold4": [
    0,                    // [0] = SOM_x (deferred to Phase 2C)
    0,                    // [1] = SOM_y (deferred to Phase 2C)
    0,                    // [2] = semantic_z (future enrichment)
    0.42                  // [3] = community_w (Phase 2B — normalized community_id)
  ]
}
```

**After Phase 2C:**
```json
{
  "manifold4": [
    0.55,                 // [0] = SOM_x / 20 (normalized to [0,1])
    0.73,                 // [1] = SOM_y / 20 (normalized to [0,1])
    0,                    // [2] = semantic_z (future enrichment)
    0.42                  // [3] = community_w (from Phase 2B)
  ]
}
```

### Glyph Record Layering

```
nes_chrom_packets (durable storage)
  ↓
glyph_records (canonical glyph layer)
  ├─ Scalar cols: id, glyphId, sourceId, community_id, centroidId, somCluster
  ├─ JSONB: topology (manifold4, SOM coords)
  ├─ JSONB: recordJson (full GlyphRecord for fidelity)
  └─ JSONB: semantic, kag_neighbors, dag_prev/next (linkage layer)
      ↓
Qdrant (search index)
  ├─ content embedding (768-dim)
  ├─ payload: glyph_id, packet_key, community_id, som_cluster
  └─ tags: source, kind, section
```

### Retrieval Use Cases

**Post-Phase 2B:**
- Graph traversal (Neo4j): "files in the same community as X"
- Topology reranking: "boost manifold4[3] similarity to top-K"

**Post-Phase 2C:**
- SOM grid proximity: "files near X in semantic space"
- 2D topology visualization: plot manifold4[0..1]

**Post-Phase 2D (future):**
- HMM-informed confidence: "how sure are we about this glyph's classification?"
- UNKNOWN rejection: "skip summaries below threshold"
