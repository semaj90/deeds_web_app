# OpenWiki design provenance

This Parent Atlas knowledge-fabric module is a native implementation informed by the public OpenWiki project (`langchain-ai/openwiki`), especially its resolver-owned evidence versions, claim preflight/reconciliation, resumable page jobs, per-page durability, generated provenance, and OKF projection patterns.

No OpenWiki runtime, SQLite persistence, Deep Agents controller, instruction-file ownership, or model-controlled network-fetch path is introduced here.
